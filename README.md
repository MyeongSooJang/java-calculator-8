# 문자열 덧셈 계산기

## 기능 요구사항

### 1. 문자열 입력
- [ ] 사용자로부터 문자열을 입력받는다
    - 빈 문자열 또는 null 입력 시 0 반환

### 2. 기본 구분자로 숫자 분리
- [ ] 쉼표(,)를 구분자로 숫자를 분리한다
    - 입력: "1,2" → 분리: [1, 2]
- [ ] 콜론(:)을 구분자로 숫자를 분리한다
    - 입력: "1:2:3" → 분리: [1, 2, 3]
- [ ] 쉼표와 콜론을 혼합하여 사용할 수 있다
    - 입력: "1,2:3" → 분리: [1, 2, 3]

### 3. 커스텀 구분자 처리
- [ ] "//"와 "\n" 사이의 문자를 커스텀 구분자로 인식한다
    - 입력: "//;\n1;2;3" → 분리: [1, 2, 3]
- [ ] 커스텀 구분자와 기본 구분자를 함께 사용할 수 없다
    - 커스텀 구분자 지정 시 해당 구분자만 사용

### 4. 숫자 검증
- [ ] 분리된 문자열이 숫자로 변환 가능한지 검증한다
- [ ] 음수가 포함되어 있으면 IllegalArgumentException 발생
    - 예외 메시지: "음수는 입력할 수 없습니다."

### 5. 덧셈 계산
- [ ] 분리된 숫자들의 합을 계산한다
    - 빈 문자열이나 null은 0으로 처리

### 6. 결과 출력
- [ ] 계산된 합을 출력한다
    - 출력 형식: "결과 : 6"

## 예외 상황
- [ ] 음수 입력 시 IllegalArgumentException
- [ ] 숫자가 아닌 값 입력 시 IllegalArgumentException
- [ ] 잘못된 커스텀 구분자 형식 시 IllegalArgumentException

## 테스트 케이스
| 입력 | 예상 출력 | 설명 |
|-----|---------|------|
| "" | 0 | 빈 문자열 |
| "1" | 1 | 숫자 하나 |
| "1,2" | 3 | 쉼표 구분자 |
| "1,2:3" | 6 | 혼합 구분자 |
| "//;\n1;2;3" | 6 | 커스텀 구분자 |
| "-1,2,3" | 예외 발생 | 음수 포함 |
